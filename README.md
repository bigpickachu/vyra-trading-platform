Plataforma de trading algoritmico com backtesting historico e paper trading em tempo real.

Tecnologias

Backend: Python e FastAPI

Frontend: React e TypeScript

Base de Dados: PostgreSQL

Infraestrutura: Docker

Como executar

Abrir o Docker Desktop.

Abrir o PowerShell e escrever: cd docker

Escrever: docker compose up -d

Abrir outra janela do PowerShell.

Escrever: cd frontend-react

Escrever: npm install

Escrever: npm run dev

Abrir o browser em http://localhost:5173

Funcionalidades

Backtest historico para Bitcoin, Ethereum e Solana.

Paper trading ao vivo com atualizacoes de cinco em cinco segundos.

Configuracoes de estrategia personalizadas.

Cinco indicadores tecnicos.
